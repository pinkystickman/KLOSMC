# HackOS 2.3.0 changes

- Added Government Remote Center multi-PC dashboard.
- Added terminal Remote Desktop streaming using a mirrored CC:Tweaked terminal window.
- Added remote keyboard, character, paste, mouse click, drag, mouse-up and scroll forwarding. Passive hover tracking is limited by the available CC:Tweaked mouse event API.
- Added authenticated remote file transfer restricted to `/public` (8192 bytes per file).
- Added authenticated remote restart and shutdown with confirmation.
- Added HackOS internal Mail over rednet with Inbox, Sent, Compose and mailbox settings.
- Added Remote and Mail applications to both editions; incoming remote control remains opt-in on each target.
- Preserved the separate read-only KL OS legacy diagnostics exploit-lab feature.
